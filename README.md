# 观玄 · 国学日历

一个纯前端的国学日历与术数排盘应用：黄历宜忌、干支四柱、真太阳时、地支时钟、大六壬、梅花易数、六爻纳甲、金口诀、奇门遁甲、紫微斗数、八字排盘与合婚。

## 功能

- **国学日历**：月历视图（公历 / 农历 / 干支 / 节日 / 节气精确到分钟）、当日黄历（宜忌、吉神凶煞、神煞方位、彭祖百忌、建除十二值、十二神黄黑道、冲煞、星宿、纳音）、干支四柱（含十神）、十二时辰吉凶、每日一句、实时天气
- **地支时钟**：罗盘式十二时辰表盘（时辰分色），北京时间与真太阳时（经度修正 + 均时差）双高亮，外圈秒针彗星拖尾，时辰养生提示
- **六壬排盘**：大六壬起课——月将加时排天地盘、四课、三传（九宗门：元首 / 重审 / 知一 / 涉害 / 遥克 / 昴星 / 别责 / 八专 / 伏吟 / 返吟）、十二天将、旬遁干、空亡、六亲、课体判定
- **梅花易数**：时间 / 数字起卦，本卦 / 互卦 / 变卦，动爻卦画，体用生克断语
- **六爻排盘**：摇铜钱（翻转动画）/ 时间 / 数字起卦，装卦（卦名 / 定宫 / 世应 / 纳甲 / 六亲 / 六神）、变卦
- **金口诀**：四位课式（人元 / 贵神 / 将神 / 地分），节换月将、晚子换日、五鼠遁、贵神顺逆布、日空与四大空亡
- **奇门遁甲**：时家拆补法定局（节气局窗 + 符头定元），九宫格盘（八神 / 九星 / 八门 / 天盘地盘干），值符值使落宫标记，天禽寄坤
- **紫微斗数**：命宫 / 身宫、五行局、十四主星、十二宫干支、四化（禄权科忌），传统命盘方形布局
- **八字合婚**：八字排盘（四柱 / 十神 / 藏干 / 纳音 / 大运，真太阳时校正 + 晚子换日）与双造合婚（生肖 / 年命纳音 / 日干 / 夫妻宫 / 五行互补 / 喜用神互补 / 神煞警示 / 大运同频，百分制评分）

## 技术栈

- Vite + React 18 + TypeScript
- [lunar-typescript](https://github.com/6tail/lunar-typescript)（农历 / 黄历 / 节气算法）
- 自研术数引擎（`src/lib/`：liuren / meihua / liuyao / jinkoujue / qimen / ziwei / bazi / hehun）
- [Open-Meteo](https://open-meteo.com/) 免费天气 API（无需 key）

## 本地运行

```bash
npm install --ignore-scripts   # 沙箱/受限环境需跳过 esbuild postinstall
npm run dev                    # http://127.0.0.1:5173
```

## 构建

```bash
npm run build
```

纯静态产物，可部署到任意静态托管（GitHub Pages / Vercel / Cloudflare Pages）。

## 说明

- 涉害课取「临位孟仲季取浅、平级复等」口径，经 144 例实测语料锁绿
- 昼夜贵人按占时划分：卯至申为昼（旦贵），酉至寅为夜（暮贵）
- 金口诀按「节」换月将（与六壬中气换将不同）；晚子时（>=23:00）换日
- 仅供学习研究传统历法与术数文化；合婚评分不构成婚恋决策建议
